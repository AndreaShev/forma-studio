# Forma Studio - Веб-сайт студии дизайна

## 📋 О проекте

Forma Studio — это чистый, современный и адаптивный веб-сайт для дизайн-студии. Проект представляет собой статический сайт, созданный для демонстрации услуг, портфолио и контактной информации студии. Сайт отличается минималистичным дизайном, интуитивно понятной навигацией и плавной работой всех интерактивных элементов.

Демо: [andreashev.github.io/forma-studio/](https://andreashev.github.io/forma-studio/)

## 🛠 Технологии

Проект построен на классическом стеке фронтенд-технологий:

- HTML5 (50.6%) — семантическая разметка и структура контента
- CSS3 (47.7%) — стилизация, анимации и адаптивный дизайн
- JavaScript (1.7%) — интерактивность и динамическое поведение элементов

## 🚀 Быстрый старт

### Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/AndreaShev/forma-studio.git
   ```

2. Перейдите в директорию проекта:
   ```bash
   cd forma-studio
   ```

3. Откройте проект в браузере:
   - Самый простой способ — дважды кликнуть на файл `index.html`
   - Или используйте любой локальный сервер (например, Live Server в VS Code, `python -m http.server` и т.д.)

Проект не требует сборки или компиляции, так как использует чистые HTML, CSS и JavaScript.

## 🎨 Особенности реализации

- Адаптивный дизайн: сайт корректно отображается на всех типах устройств
- Модульная структура CSS: стили организованы по логическим блокам
- Интерактивные элементы: реализованы с помощью чистого JavaScript
- Семантическая верстка: использование современных HTML5-тегов для улучшения доступности и SEO
